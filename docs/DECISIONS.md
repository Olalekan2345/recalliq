# Decisions and deviations from the original specification

| Topic                  | Decision                                                                                                           | Why                                                                                                                                                                                                                                                                                                                                   |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ORM                    | **Drizzle** (spec allowed Prisma or Drizzle)                                                                       | Runs the same SQL migrations on PostgreSQL in production and on PGlite (real Postgres in WASM) in tests, with no Docker.                                                                                                                                                                                                              |
| Auth                   | **Better Auth** (email/password + anonymous guests)                                                                | Mature, database sessions, Drizzle adapter, guest→account data linking.                                                                                                                                                                                                                                                               |
| Queue                  | **Postgres job table** with `FOR UPDATE SKIP LOCKED` leases                                                        | Durable, idempotent, restart-safe, no Redis needed.                                                                                                                                                                                                                                                                                   |
| Streaming              | **SSE** polling the execution trail in Postgres                                                                    | Works across the web and worker processes; resumable with `Last-Event-ID`.                                                                                                                                                                                                                                                            |
| Tatum transport        | **Native gRPC** (`@grpc/grpc-js` via protobuf-ts) with the official `sui.rpc.v2` clients from `@mysten/sui`        | Matches Tatum's documented `x-api-key` metadata. Verified live: Tatum serves `GetTransaction`, `ListTransactions` (affected-address index), `GetCoinInfo`, `ListBalances` and checkpoints.                                                                                                                                            |
| Address history        | Tatum `LedgerService/ListTransactions`                                                                             | Available on Tatum, so no non-Tatum indexer is needed. `SUI_FALLBACK_GRPC_URL` exists only for methods Tatum reports `UNIMPLEMENTED`, and provenance discloses it.                                                                                                                                                                    |
| x402 facilitator       | **Self-facilitation through Tatum** by default; a remote facilitator is optional                                   | The only public Sui facilitator found (DrVelvetFog/sui-x402-facilitator) is an unaudited hackathon project whose hosted instance advertises testnet. Self-facilitation keeps settlement non-custodial and makes Tatum the execution path. Remote mode implements the x402 v2 `/verify` + `/settle` API for a self-hosted facilitator. |
| Paid specialist        | **First-party** x402 API (`/api/x402/forensics`)                                                                   | No reliable independent Sui x402 analytics API was found. The service performs real computation, and the operator relationship is disclosed in the UI, quote and tool description.                                                                                                                                                    |
| Payment tx building    | Server builds the exact transfer via Tatum; the wallet only signs                                                  | The browser needs no RPC credentials, and the server re-verifies whatever comes back.                                                                                                                                                                                                                                                 |
| Lesson generation      | **Deterministic templates + evidence**, never LLM-written explanations                                             | Spec: "Do not ask an LLM to invent a convincing explanation for a failure."                                                                                                                                                                                                                                                           |
| Behaviour change       | Directives enforced in `submit_final_report` and WorthIt, not just prompt text                                     | Makes "changed decision" measurable and recorded.                                                                                                                                                                                                                                                                                     |
| Default model          | Anthropic `claude-opus-5-5` with adaptive effort (standard → medium, deep → high) and server-side refusal fallback | Most capable current default with a verified price table. Other providers must set `LLM_MODEL` explicitly; their cost is "unknown" unless prices are configured.                                                                                                                                                                      |
| MemWal SDK             | Pinned `0.1.8`                                                                                                     | Proven in the operator's previous project. `0.1.9` was published on the day of the build.                                                                                                                                                                                                                                             |
| Evaluation conclusions | Two-sided exact sign test; fewer than 5 informative pairs or p ≥ 0.05 means **inconclusive**                       | Prevents claiming improvements that the data cannot support.                                                                                                                                                                                                                                                                          |
| Deletion               | Retraction (excluded from recall)                                                                                  | Walrus storage is append-only; the UI states this.                                                                                                                                                                                                                                                                                    |
