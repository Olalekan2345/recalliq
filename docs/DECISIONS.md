# Technical decisions

| Topic                  | Decision                                                                                                                                                                       | Rationale                                                                                                                                                                                                                                      |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ORM                    | **Drizzle**                                                                                                                                                                    | Runs the same SQL migrations on PostgreSQL in production and on PGlite (real Postgres in WASM) in tests, with no Docker.                                                                                                                       |
| Auth                   | **Better Auth** (email/password + anonymous guests)                                                                                                                            | Mature, database sessions, Drizzle adapter, guest→account data linking.                                                                                                                                                                        |
| Queue                  | **Postgres job table** with `FOR UPDATE SKIP LOCKED` leases                                                                                                                    | Durable, idempotent, restart-safe, no Redis needed. The same queue runs with an inline worker, a dedicated worker, or serverless drains (see [DEPLOYMENT.md](DEPLOYMENT.md)).                                                                  |
| Streaming              | **SSE** polling the execution trail in Postgres                                                                                                                                | Works across the web and worker processes; resumable with `Last-Event-ID`.                                                                                                                                                                     |
| Tatum transport        | **Native gRPC** (`@grpc/grpc-js` via protobuf-ts) with the official `sui.rpc.v2` clients from `@mysten/sui`                                                                    | Matches Tatum's documented `x-api-key` metadata. Verified live: Tatum serves `GetTransaction`, `ListTransactions` (affected-address index), `GetCoinInfo`, `ListBalances` and checkpoints.                                                     |
| Address history        | Tatum `LedgerService/ListTransactions`                                                                                                                                         | Available on Tatum, so no separate indexer is needed. `SUI_FALLBACK_GRPC_URL` exists only for methods Tatum reports `UNIMPLEMENTED`, and provenance discloses it.                                                                              |
| x402 facilitator       | **Self-facilitation through Tatum** by default; a remote facilitator is optional                                                                                               | No production Sui mainnet facilitator was available (the public one found is an unaudited community project whose hosted instance targets testnet). Self-facilitation keeps settlement non-custodial and makes Tatum the execution path. Remote mode implements the x402 v2 `/verify` + `/settle` API for a self-hosted facilitator. |
| Paid specialist        | **First-party** x402 API (`/api/x402/forensics`)                                                                                                                               | No reliable independent Sui x402 analytics API was found. The service performs real computation, and the operator relationship is disclosed in the UI, the quote and the tool description.                                                    |
| Payment tx building    | Server builds the exact transfer via Tatum; the wallet only signs                                                                                                              | The browser needs no RPC credentials, and the server re-verifies whatever comes back.                                                                                                                                                          |
| Lesson generation      | **Deterministic templates + evidence**, never LLM-written explanations                                                                                                         | A failure explanation must come from evidence, not from a model asked to produce a convincing story.                                                                                                                                          |
| Behaviour change       | Directives enforced in `submit_final_report` and WorthIt, not just prompt text                                                                                                 | Makes "changed decision" measurable and recorded.                                                                                                                                                                                              |
| Language model         | Provider-agnostic through the Vercel AI SDK (Anthropic, OpenAI, Groq, Google). Code default: Anthropic `claude-opus-5-5`. Production deployment: Google `gemini-3.5-flash-lite` | Tools, budgets, verification and policy enforcement do not depend on the provider, so each deployment chooses its model for cost and latency. Token cost is reported only for models with a configured price table, otherwise "unknown".     |
| MemWal SDK             | Pinned `0.1.8`                                                                                                                                                                 | Exact version pin for reproducible builds; upgrades are adopted deliberately after the test suite passes.                                                                                                                                     |
| Evaluation conclusions | Two-sided exact sign test; fewer than 5 informative pairs or p ≥ 0.05 means **inconclusive**                                                                                   | Prevents claiming improvements that the data cannot support.                                                                                                                                                                                   |
| Deletion               | Retraction (excluded from recall)                                                                                                                                              | Walrus storage is append-only; the UI states this.                                                                                                                                                                                             |
